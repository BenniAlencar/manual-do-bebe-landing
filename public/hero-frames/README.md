# Hero frames — desktop

Coloque aqui a sequência desktop do hero de scroll cinematográfico.

Convenção obrigatória:
- `hero-01.webp` até `hero-10.webp`
- orientação recomendada: paisagem/cinemática, 1920 × 1080 px ou superior
- formato preferido: WebP
- sem texto, logo ou marca-d'água embutidos
- preserve área negativa à esquerda para a copy HTML
- manter o mesmo bebê, adulto, cobertor, ambiente e progressão de luz em toda a sequência

Os assets serão carregados pelo componente ScrollHero após a implementação.
