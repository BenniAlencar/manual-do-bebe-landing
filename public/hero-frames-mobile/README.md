# Hero frames — mobile

Coloque aqui a sequência mobile do hero de scroll cinematográfico.

Convenção obrigatória:
- `hero-01.webp` até `hero-10.webp`
- orientação recomendada: vertical, 1080 × 1920 px
- formato preferido: WebP
- sem texto, logo ou marca-d'água embutidos
- preserve área negativa à esquerda ou no terço inferior para a copy HTML
- manter o mesmo bebê, adulto, cobertor, ambiente e progressão de luz em toda a sequência

Os assets serão selecionados em telas mobile pelo componente ScrollHero após a implementação.
